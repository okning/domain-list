Usage examples

Examples use the github rule set and the PROXY policy. 

[Rule]
RULE-SET,https://domain-list.nosec.me/surge/github.txt,PROXY,"update-interval=86400"

Add this line to the [Rule] section of your Surge configuration. 

rule-providers:
  github:
    type: http
    behavior: classical
    format: yaml
    url: https://domain-list.nosec.me/clash/github.txt
    path: ./ruleset/github.yaml
    interval: 86400

rules:
  - RULE-SET,github,PROXY

For Clash/Mihomo cores that support rule-providers.
